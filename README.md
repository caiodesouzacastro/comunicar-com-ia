# Comunicar evidências com IA

Página de apoio sobre como usar IA para transformar uma síntese em versões curtas sem mudar o que a evidência diz.

- `index.html`: a página, com o caminho de trabalho, erros e soluções, um exemplo conferido, ferramentas e o kit.
- `assets/`: capturas do teste conferido, com nomes de instituição ocultados.
- `downloads/`: prompts por etapa, três modelos em Word, checklist, planilha de conferência, instruções para projeto e skill para o Claude.

Feita para publicar pelo GitHub Pages.
